# ADR-0001: New AI-first Latent-Risk repository

**Date:** 2026-10-16  
**Status:** Accepted

## Problem
The earlier U.S.-only repository mixes pilot index extraction, trend estimation utilities, plots and unrelated existing research. Research continuity across AI sessions requires a standard authoritative chronology.

## Alternatives
1. Extend the old U.S.-risk repository in place.
2. Keep the new study as another working paper in Trend-Estimation.
3. Create `Latent-Risk` with independent `src/`, journal, literature and article structures.

## Decision
Choose option 3. Preserve old repositories without copying claimed results. Implement `src/latent_risk`, tests, notes, journal, literature/{pdf,markdown,references}, paper, experiments and AI handoff.

## Rationale
The applied research question, source data and statistical model comparisons differ from the theoretical smoothing paper; continuous research journals make context recovery reliable.

## Consequences
More initial scaffolding, but clearer tests and provenance. Earlier jointly authored artifacts require citation/attribution discussion before reuse. The repo is not a certified publication package yet.
