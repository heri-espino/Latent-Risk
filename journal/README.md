# Research journal — read before AI_HANDOFF

The journal is the chronological and append-only record of scientific decisions and outcomes. At the start of every session, read this README, [LATEST.md](LATEST.md), and the linked dated entry **before** the summarized handoff.

Use `journal/YYYY-MM/YYYY-MM-DD-topic.md` for work sessions. Each entry must report date/objective, motivation, questions, work performed, exact files changed, reasoning, implementation, experiments, unexpected results, failures, alternatives, limitations, validation commands/results, supported conclusions, and next steps.

Do not erase negative findings. When a past result proves incorrect, add a new dated correction and refer to the original entry. Structural decisions also require an ADR under `journal/decisions/`.
