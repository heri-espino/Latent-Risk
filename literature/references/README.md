# Annotated literature records

Each paper card must state bibliographic identity, objective, assumptions, notation, important equations/results with verified source pages where available, methods, relevance, limitations and verification status. Start from [PAPER_TEMPLATE.md](PAPER_TEMPLATE.md) and add the citation key to [../MANIFEST.csv](../MANIFEST.csv) and [library.bib](library.bib).

**Source rights:** Never upload a non-redistributable publisher personal copy to a public GitHub repository. A summary is not a substitute for verifying exact formulas against the source PDF.
