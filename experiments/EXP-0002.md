# EXP-0002 — Retrospective CISS rolling-origin forecasting baselines

**Status:** `IMPLEMENTED; TESTED SYNTHETICALLY; NOT EXECUTED ON USER VM`.  
**Design type:** exploratory numerical/evaluation proof-of-concept, **not** pseudo-real-time research evidence and **not** the substantive latent-index experiment EXP-0001.  
**Configuration:** [configs/EXP-0002.json](configs/EXP-0002.json).  
**Implementation:** `src/latent_risk/data/ciss_baselines.py`; `scripts/run_ciss_baselines.py`.

## Question and purpose
Can a reproducible, truly one-sided **sequence-of-observations** forecasting pipeline operate on three observed financial-stress reference series (ECB US, UK and euro-area CISS) while avoiding future numerical data in parameter selection? This tests the chronological evaluator before constructing country-specific *latent* market/bank/credit stress factors.

The target for country `c` is **the currently downloaded ECB CISS index itself**, `y_{c,t}`. No market-price features and no published CISS other than that same target's past history are predictors in this experiment. Thus this experiment **does not test whether market-derived features predict external stress**.

## Inputs and provenance
Use only `external_stress_references.csv` from the latest already-generated `data/processed/market_pilot/<snapshot>`; verify derived CSV SHA256 against the pilot manifest. Use only provider ECB + three prespecified CISS country codes. FRED STLFSI4 and NFCI remain entirely excluded from this benchmark exercise, as do all equity/FX features. Record source manifest SHA256, code commit, exact config and output hashes in a new ignored timestamped `results/runs/EXP-0002` folder.

**Severe vintage caveat:** Data are current-vintage historical observations, not archived values historically known on their observation date. We do not assert any actual `available_date` nor call the backtest genuine real-time forecasting. The pseudo-real-time protocol for EXP-0001 remains undecided.

## Fixed exploratory evaluation choices
- Model **one country at a time**; no shared scaling, cross-country factor definition or pooled RMSE rankings.
- First *outer* forecast origin on or after **2008-01-01**, with at least 504 CISS observations in training; expanding observation history.
- Outer origins spaced **21 reported CISS observations**. Horizon `h∈{1,5,21}` **reported observations**, not trading/calendar days, with matched origin/target pairs for every method.
- `persistence`: predict last observed `y_t`.
- `ar1_ols`: estimate `y_{j+1}=a+b y_j+e_{j+1}` using at most the last 504 historical observations ending at origin; recursively compute h-step forecast. No outcome beyond origin used to fit.
- `ewma_nested_cv`: choose one-sided recursive EWMA gain `α∈{0.05, 0.10, 0.25, 0.50, 0.85, 1}` by **nested chronological CV** inside the most recent 504 observations: earliest inner origin after 252 observations; inner origins every 21; each inner forecast targets `j+h` no later than outer origin. Minimize mean squared h-step validation error and choose the first gain in case of ties. Predict the latest 252-observation EWMA level as a flat h-step baseline. Gain α=1 reduces to persistence.
- `EWMA ≠ Whittaker–Henderson / second-difference PLS / marginal MLE`. This is a computational smoothing benchmark, **not** the project's primary forecast-optimal penalized-smoothness method.
- Metrics: RMSE and MAE **within each same CISS target and horizon**, on matched origins. No aggregate across different-country targets; no conventional volatility/credit controls or inferential significance yet.
- There is no random seed because all three methods and origin grids are deterministic. The source data have current-vintage revisions; calendar and release availability are outside this test.

## Leakage protections and known scope
The implementation uses the chronological CISS array and origin slicing. Outer predictions only consume indices `≤t`; within-origin alpha CV uses only inner targets whose index `≤t`; no full-sample normalization or selection using outside-origin data. Synthetic tests modify future observations to check causal invariance. No claim of held-out event selection or definitive model superiority is allowed.
