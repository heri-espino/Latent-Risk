# Literature reading workflow

All papers are registered in [MANIFEST.csv](../literature/MANIFEST.csv). Use a consistent citation key for original PDF (only if legally distributable), Docling Markdown extraction, and an annotated card in `literature/references/`.

Before extracting a theorem or equation, record source, assumptions, page/equation number **if verified**, limitations and relationship to the project. Verify technical claims against the original rather than assuming Docling extracted symbols perfectly. See [KEY_RESULTS.md](../literature/references/KEY_RESULTS.md).

The current bibliography includes high-level verified notes for Guerrero (2007), Islas et al. (2019) and Biessy (2026). The new cross-country model and results do not yet have a complete literature review.
