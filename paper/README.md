# Manuscript — work in progress

Working title: *When Do Smoothed Financial Risk Indicators Fail to Forecast? Evidence Across Countries and Financial Disturbances*.

Build a local PDF from `paper/main.tex` using any standard LaTeX distribution:

```bash
cd paper
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Results are deliberately absent. This article is an applied empirical project about reliability of smoothed latent-risk forecasts; it is **not** a second paper claiming the theoretical/numerical smoothing innovations developed in the separate Trend-Estimation project. Publication outlet remains provisional. Manuscript authorship awaits confirmation with relevant contributors of the earlier U.S. work.
